📖 How to Sync Your Data

GitHub Syncing

  1. Go to Settings → Secrets and variables → Actions
  2. Add GITHUB_USERNAME with your username
  3. Add GH_SYNC_TOKEN with a personal access token from github.com/settings/tokens
  4. Go to Actions → Sync Activity Data → Run workflow

Strava Syncing (Optional)

  1. Create an app at strava.com/settings/apps
  2. Note your Client ID and Client Secret
  3. Get a refresh token via OAuth (see README for details)
  4. Add these 3 secrets to your repo:
    • STRAVA_CLIENT_ID
    • STRAVA_CLIENT_SECRET
    • STRAVA_REFRESH_TOKEN

Data syncs daily via GitHub Actions. See README for detailed instructions.
